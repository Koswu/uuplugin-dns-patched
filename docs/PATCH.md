# 补丁实现及已有实测

## 修改范围

从先前基础设施仓库提取已验证的 Python 工具和测试，二进制修改位置和逻辑保持一致，新增官方原始文件的精确输入、输出校验档案。只接受 README 所列 SHA256；输出大小与各自原文件相同：官方原始文件 5,210,480 字节，先前 AUR 安装文件 5,210,584 字节；两者均修改 285 个字节。两种原文件的 .text 与 .rodata 逐字节一致，先前安装文件带有打包生成的 ELF 调试链接信息。

- 文件偏移 `0x3e0998`、`0x3e0b00`：IPv4 DNS DNAT 添加、删除的命令模板；保留 printf 参数顺序，加入 Tailnet 目的地址排除。
- `0x3e1410` 至 `0x3e1470` 的共享常量：IPv6 TCP/UDP DNS DROP 添加、删除命令，加入 Tailnet IPv6 前缀排除。
- 四组 IPv6 命令构造指令的立即数尾部：改为空格，保持指令长度。具体偏移、原始字节及替换字节见 `dns_edits()`。

定长替换会移除这些命令原有的输出重定向，命令错误可能出现在服务日志中。没有修改认证、计费、加速节点选择或应用协议。

IPv4 排除的是整个 CGNAT `100.64.0.0/10`，不只 MagicDNS 单一地址；这些地址的 DNS 会绕过 UU 重定向。IPv6 同样排除整个 Tailnet ULA 前缀。不要将这理解为为所有 VPN 提供兼容。

## 2026-10-28 隔离实验（历史证据）

环境：Arch Linux Incus 虚拟机、UU 14.2.2、Tailscale 1.104.2、NetworkManager 直接管理 resolv.conf。手机 App 绑定独立虚拟机设备并真正开启 Steam 商店加速。宿主机未安装补丁。

负对照：原版 UU 加速时，IPv4 MagicDNS UDP 和 IPv6 DNS 超时；IPv4 TCP 正常。预先添加静态例外也无效，因为 UU 后启动加速会将新规则插到最前。

补丁实验移除了此前的事件监听及手工例外规则，单独运行补丁程序：

- 实际捕获加速、停止、重新加速；停止时规则清理，重启后自行重建。
- 长采样 592 个样本、1776 次查询，两次 1 秒超时自行恢复；其中一次为内网 IPv6 DNS。原因未确定，不能宣称全程无故障。
- 完整 DNS 矩阵 94 项通过：内网 A/AAAA、双栈 MagicDNS UDP/TCP、系统解析器及公共域名。
- UU 和 Steam HTTPS 返回 200。
- 内网目的地址走 tailscale0，Steam 目的地址走 tun163。

这份记录来自之前的隔离实验，仓库提取后的构建验证不等于重新进行真人 App 加速测试。未验证其它游戏、其它 UU 版本、上游自更新或长期稳定性。上游或其它安装工具替换二进制后可能丢失补丁，应核对 `/usr/bin/uuplugin` 的 SHA256。

## 适配新版

先取得新官方文件，核对架构和规则构造函数，重新反汇编并确认所有添加、删除路径；添加对应测试后在独立虚拟机做原版负对照及真实 App 启停。记录新输入、输出摘要和限制，才能更新补丁档案及 PKGBUILD。不要仅替换哈希来跳过分析。
